# Validação 0.1.0

- Arquivo original identificado por SHA-256 e preservado.
- Jogo iniciado pela Steam no ROG Ally X/Bazzite, após fechar os outros jogos.
- Corrida observada, com aceleração, direção e exibição de km/h e metros/km.
- Controles físicos confirmados pelo usuário após correção do ambiente SDL.
- Tradução inglesa aplicada: 1.360 arquivos de dados, com backup japonês.
- HUD e legendas inglesas observados durante corrida.
- Pausa: duas capturas separadas por três segundos foram idênticas.
- Retomada: cronômetro de 5,380 s para 7,610 s após aproximadamente 2 s de
  jogo retomado; o intervalo pausado não foi somado.
- Cinco artes locais aplicadas via Steam e verificadas por SHA-256.
- Código Python compilado para verificação de sintaxe.

Não validados: todos os capítulos, modos online, cartões, progressão persistente,
volantes físicos, nem uma medição extensa de desempenho. O original japonês é
preservado no arquivo fornecido pelo usuário; o patch tem backup separado.
